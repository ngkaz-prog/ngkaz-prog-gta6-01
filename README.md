SOLMAR HEAT is an original open-world crime game that runs offline in a desktop browser: steal and drive cars through the sun-soaked coastal city of Solmar, outrun the police across a 5-star wanted system, and run six story missions for Rico Marlow — with traffic, pedestrians, combat, a HUD with minimap, synthesized sound and music, and a save.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network request: every file the game loads lives under `game/`.
